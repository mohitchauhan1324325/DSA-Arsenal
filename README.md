## 🎯 Purpose

This repository is built for **DSA revision**, not just storing solutions.

The goal is to maintain one place where I can quickly revise:

- Important concepts
- Common problem-solving patterns
- Reusable code templates
- Solved problems
- Important observations and edge cases
- Mistakes and approaches

The focus is on **understanding patterns and being able to solve similar problems independently**.

## 🧪 Problems

Problems are organized according to their **topic and pattern**.

Each problem should help answer:

> **What pattern does this problem use?**

For every important problem, keep:

```text
Problem
├── Pattern
├── Intuition
├── Approach
├── Complexity
├── Code
└── Important Edge Cases
```

Example:

```text
04-Stack/
└── Monotonic-Stack/
    ├── next-greater-element.cpp
    ├── daily-temperatures.cpp
    ├── largest-rectangle.cpp
    └── sum-subarray-minimums.cpp
```

The purpose is not to collect hundreds of solutions.

The purpose is to build a **small set of representative problems for each pattern** so that the pattern can be revised quickly.

---

## 🧠 Problem-Solving Checklist

Before looking at a solution:

```text
1. Understand the problem
2. Check constraints
3. Think of brute force
4. Identify the pattern
5. Choose the data structure
6. Optimize
7. Test edge cases
8. Analyze Time & Space Complexity
9. Code
```

---

## 🔁 Revision

For every important problem:

```text
First Solve
     ↓
Understand the Pattern
     ↓
Write the Intuition
     ↓
Re-solve Without Looking
     ↓
Revise Later
```

When revising, focus on:

- **Pattern**
- **Core idea**
- **Why the approach works**
- **Template**
- **Complexity**
- **Common mistakes**
