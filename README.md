## 🧪 Problem Format

Problems are organized by topic, pattern, and difficulty whenever useful.

<details>
<summary><b>📂 Example Structure</b></summary>

```text
04-Stack/
├── README.md
├── Templates/
│   └── monotonic-stack.md
├── Basics/
├── Parentheses/
├── Monotonic-Stack/
│   ├── next-greater-element.cpp
│   ├── daily-temperatures.cpp
│   ├── largest-rectangle.cpp
│   └── sum-subarray-minimums.cpp
└── Problems/
```

</details>

Each problem should ideally contain:

- **Problem Name**
- **Pattern**
- **Intuition**
- **Approach**
- **Complexity**
- **Code**
- **Important Edge Cases**
